UCI reference

Owen speaks standard UCI. Anything here works in Cutechess, Knights, Arena and OpenBench.

Minimal session

$ ./owen2
o2 > uci
id name Owen 2
id author Owen Foundation
option name Hash type spin default 64 min 1 max 16384
...
uciok
o2 > isready
readyok
o2 > position startpos moves e2e4 e7e5
o2 > setoption name Threads value 8
o2 > go depth 22
info depth 19 seldepth 19 score cp 5 nodes 12000 nps 34582 time 347 pv b1c3
bestmove b1c3 ponder a7a6

Commands

CommandMeaning
uciIdentify; lists id and all option lines, ends with uciok.
isreadySynchronize; always answered with readyok.
ucinewgameReset board, clear search state, start a new game.
position startpos [moves ...]Set from the initial position plus a move list.
position fen <fen> [moves ...]Set from any FEN plus a move list.
setoption name <n> value <v>Change an option (see table below).
go depth NSearch with a visit budget mapped from N (4 ≈ 12k visits).
go movetime MSHard time limit in milliseconds.
go wtime WT btime BT [winc WI binc BI]Clock game; time is split with overhead guards.
go infinite / go ponderSearch until stop / ponderhit.
go nodes N / go mate NStop after N visits / on forced mate proof.
stopEnd the search now and emit bestmove.
ponderhitThe ponder move was played; convert ponder to normal search.
d / displayPrint the current board/FEN (debugging).
perft [n]Move-generation verification counts.
bench [depth]Deterministic startpos bench to stdout (see below).
quitStop everything and exit.

Output anatomy

info depth 19 seldepth 19 score cp 5 nodes 12000 nps 34582 time 347 pv b1c3
bestmove b1c3 ponder a7a6
  • depth is the maximum tree depth reached; seldepth tracks it too (best-first search has no classic iterations).
  • score is side-to-move centipawns, or mate N for proven mates.
  • nodes/nps/time are visits, visits-per-second and milliseconds.
  • bestmove is always emitted exactly once; 0000 means no legal moves.

Bench (deterministic)

$ ./owen2 bench 6
bench depth 6 nodes 32000 nps 1127 time 28383ms bestmove e2e4 evalhit 26.5%

One stdout line, depth clamped to 1–10. Node counts are identical on every machine for the same binary — DefenceTest uses them as run signatures to prove workers built the right engine.
