Reference

Types & glossary

One page for every name, unit and shape used across engine, files and API.

Engine types

TermMeaning
Bitboard64-bit integer, one bit per square.
MovePacked from/to/promotion; UCI form is e2e4, promotions append the piece (e7e8q).
PositionBoard + side to move + castling + en-passant + clocks + Zobrist key.
ValueCentipawns, side-to-move perspective; mates encoded near ±30000.
SearchResultbestMove, ponderMove, score, depth (max reached), nodes, time_ms.
SearchLimitsBounds for one search: depth, nodes, movetime_ms, clock fields, infinite/ponder, mate.
FEN / EPDPosition notation; EPD lines form opening books (one FEN per line).
PGNRecorded games with results and (when available) [%eval] annotations.

Network & data types

TermMeaning
.o2nnVersioned NNUE container (magic O2NN). See Network format.
HalfKP / ThreatFeature sets: king-relative piece squares + attacked-square flags; 81920 inputs total.
sdataTraining samples; v2 lines are 71 bytes (position, outcome, rights).
bench signatureDeterministic bench 6 node count (32000 for v14) proving a build's identity.

Worker API shapes

TermMeaning
worker_infoHeartbeat identity: username, concurrency, compiler, worker_arch (x86_64/arm64), unique_key, remote_addr.
run argsA test's definition: tags, SHAs, nets, TC, book, games, options, signatures, author.
taskA slice of a run (num_games, opening offset); workers report stats per batch.
statswins/losses/draws/crashes (+ pentanomial); only validated batches count.
book_sriBase64 sha384 of the opening book; workers verify before playing.

Units & testing terms

TermMeaning
npsNodes (visits) per second; machine speed, not strength.
Elo / nEloRating difference and its normalized form; always quoted with error bars.
SPRTSequential Probability Ratio Test: stops early on proof, bounds like [0, 5].
STC / LTCShort / long time control brackets.
PentanomialGame-pair statistics (WW, WD, WL, DD, LL) that halve variance.
LOSLikelihood of superiority: probability the patch is stronger.
approved / approverRun gate: approvers and 500-game contributors start instantly, others wait once.
games_playedPer-account lifetime contributed games; drives the reputation above.
