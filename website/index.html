Why Owen

Different by design

Modern engines proved that NNUE evaluation plus excellent engineering wins. Owen keeps the lesson and replaces the search itself.

◎

Marrow Tree Search

A best-first, proof-guided tree search with UCB1 selection and NNUE leaves. Depth is allocated by uncertainty, not a fixed reduction schedule.

▦

Original NNUE

HalfKP + Threat feature transformer feeding affine layers, trained end-to-end from self-play data. Weights ship as versioned .o2nn files.

∅

No alpha-beta baggage

No null-move pruning, no fragile late-move reductions, no razor/futility heuristics — and nothing derived from other engines' sources.

⌘

Readable core

Bitboards, magic move generation, Zobrist hashing and a clean UCI loop. Small enough to audit, fast enough to matter.

⇅

Train your own net

A Python/PyTorch trainer turns self-play samples into a network. Distillation recipes for stronger teachers are documented too.

⬡

Runs anywhere

Prebuilt binaries for Windows, Linux, macOS and ARM, plus an OpenBench-compatible Makefile that embeds the network at build time.

Architecture

Small surface, clear seams

The engine is organised so each concern lives in one place — board state, move generation, evaluation, and search stay independent and testable.

  • Perft-verified move generation (Kiwipete 97862)
  • Threaded search with a sharded transposition table
  • UCI options for hash, threads, network and exploration

Community testing

Powered by DefenceTest

Owen's strength comes from thousands of self-play and match games. DefenceTest is the open distributed test framework that runs those games — and it needs volunteers.

  • Donate spare CPU time and get credited on the leaderboard
  • Automatic updates, native Windows/Linux/macOS workers
  • Results stream straight back to the project — no manual uploads
Open the test server How it works
Run a worker 
# 1. create an account (auto-approved): open the test server above, /signup
# 2. get the worker: git clone https://github.com/Owen-Foundation/DefenceTest
# 3. run it with YOUR account + the full --host (no GPU needed, https/443)
python worker.py USERNAME PASSWORD --host zoloft-roland-playstation-motorcycles.trycloudflare.com --port 443
# needs: python3.8+, C++ compiler, make, cmake. Omit --host only for a local server.

Games are played by your worker and submitted automatically; the server aggregates W/D/L, Elo and SPRT statistics for every patch.
