# Security Policy

## Reporting a Vulnerability

Please report security issues privately to **Owen Foundation** (open a private security advisory on GitHub or contact the maintainer directly). Do not open a public issue for vulnerabilities.

## Scope

Owen 2 is a local UCI chess engine with no network code. Attack surface is limited to UCI input parsing, FEN/position handling, and file I/O for network weights.
